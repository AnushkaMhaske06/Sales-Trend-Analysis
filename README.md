# Sales Trend Analysis

## Project Overview
This project analyzes sales data using Python.
It explores monthly sales trends and compares
sales across different product categories.

## Tools Used
- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## Analysis
- Monthly Sales Trend using a Line Chart
- Category-wise Sales using a Bar Chart
- Category Sales Share using a Pie Chart
- Sales Summary Report

## Key Findings
- Total Sales: $2,326,534.35
- Total Profit: $292,296.81
- Best-Selling Category: Technology
- Unique Orders: 5,111

## Project Files
- sample_-_superstore.xls: Dataset
- summary.txt: Sales summary
